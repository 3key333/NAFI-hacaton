# NAFI — «Цифровой гражданин»

Репозиторий фронтенда лендинга платформы **«Цифровой гражданин»** (НАФИ) — сервиса для оценки и развития цифровых компетенций сотрудников и студентов.

## Состав репозитория

| Путь | Описание |
|------|----------|
| [`client/`](./client/) | SPA на React + TypeScript (Vite) — лендинг, конфигуратор, визард, демо-панель |

Backend в репозитории отсутствует: формы, оплата и договор реализованы как mock на клиенте.

## Быстрый старт

```bash
cd client
npm install
npm run dev
```

Приложение: `http://localhost:5173`  
Демо-панель: `http://localhost:5173/panel`

Подробная документация — в [`client/README.md`](./client/README.md).

## Основные возможности

- **Лендинг** — 13 секций с контентом о продукте, кейсами, FAQ и контактами
- **Конфигуратор** — число тестируемых и доп. опции; цена с НДС 5%
- **5-шаговый визард** — от параметров до mock-оплаты и экрана успеха
- **Демо-панель** — ознакомительный UI отчётов по адресу `/panel`
- **Модалка консультации** — заявка с валидацией (отправка имитируется)

## Требования

- Node.js 18+
- npm 9+
